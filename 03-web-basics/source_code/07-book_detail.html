채식주의자

한강 · 창비 · 한국 문학

한 권의 책이 남기는 질문을 따라,
서로 다른 시선으로 이야기를 읽습니다.

『채식주의자』를 주제로 한 상세페이지 UI입니다. 도서를 보관하고 관련 독서 이야기를 탐색할 수 있도록 구성했습니다. 도서 정보와 아래 쓰레드는 화면 구성 시연용이며, 실제 서비스의 소장 정보·리뷰 DB와는 연결되어 있지 않습니다.
