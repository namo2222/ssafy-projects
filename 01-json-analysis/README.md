# 도서 JSON으로 살펴보는 가격과 시리즈

도서 목록에서 출간월별 평균 판매가를 계산하고, 개별 도서 정보를 카테고리와 시리즈별 JSON으로 묶는 Python 프로젝트입니다.

![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white)

**SSAFY 관통 프로젝트 01** · 2026.07.29 · 오유나, 이남호

## 프로젝트 개요

같은 도서 데이터도 질문에 따라 묶는 기준이 달라집니다. 가격을 비교할 때는 출간월별로 판매가를 집계하고, 책을 찾아볼 때는 카테고리나 시리즈 ID를 기준으로 도서 목록을 구성합니다. 각 작업은 독립된 스크립트로 실행합니다.

## 기술 스택

| 기술 | 사용한 곳 |
| --- | --- |
| Python | 출간월을 키로 하는 딕셔너리에 도서 수와 판매가 합계를 누적해 월별 평균을 계산합니다. |
| `json` · Python 표준 라이브러리 | 도서 파일을 읽고 카테고리별로 가공한 목록을 한글이 유지되는 JSON 파일로 저장합니다. |
| `pathlib` · Python 표준 라이브러리 | `Path.rglob("*.json")`으로 하위 폴더에 흩어진 시리즈 도서 파일을 찾습니다. |

## 핵심 구현

### 출간월별 평균 판매가

출판일에서 월을 꺼내 해당 월의 도서 수와 판매가 합계를 누적합니다. 월별 합계를 권수로 나누어 1월부터 순서대로 출력하며, 출판 연도가 달라도 같은 달에 나온 책은 함께 집계합니다. [월별 통계 코드](source_code/problem_C1.py)

### 카테고리별 도서 목록

도서 배열을 순회하며 카테고리 ID를 키로 사용합니다. 각 카테고리에 분류명과 도서 목록을 두고, 책마다 제목·저자·출판사·출판일·ISBN·판매가를 골라 저장합니다. 결과는 한글을 그대로 읽을 수 있는 JSON 파일로 기록합니다. [카테고리 변환 코드](source_code/problem_C2.py)

### 여러 파일에 흩어진 시리즈 병합

하위 폴더까지 JSON 파일을 탐색해 시리즈 정보가 있는 책을 고릅니다. 같은 시리즈 ID를 가진 책은 하나의 목록에 모으고, 시리즈 이름과 함께 `data/series.json`에 저장합니다. [시리즈 병합 코드](source_code/problem_C3.py)

## 실행 방법

Python 환경에서 저장소 루트를 작업 폴더로 엽니다. 카테고리별 목록을 만들려면 도서 객체 배열이 담긴 입력 파일을 `data/books_2000.json`에 준비한 뒤 실행합니다.

```bash
python source_code/problem_C2.py
```

결과는 `data/category_books.json`에 저장됩니다. 같은 경로에 기존 결과가 있으면 새 내용으로 덮어씁니다.
